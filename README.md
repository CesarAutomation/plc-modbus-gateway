# plc-modbus-gateway

Industrial integration project: PLC (Ladder + Structured Text) ↔ Modbus TCP ↔ Python gateway.

## Overview

This repository contains a practical integration between a PLC and a Python-based
gateway, demonstrating industrial communication over Modbus TCP.

The project is part of a structured roadmap toward becoming an
Embedded Control / Industrial Embedded Systems Engineer, with a focus on
real-world industrial integration and professional Git workflow.

## Status

🚧 **In development** — Phase B (Industrial Integration) of the roadmap.

## Structure

- `plc/` — PLC programs (Structured Text, Ladder exports, screenshots)
- `gateway/` — Python Modbus client, logging, simulator
- `docs/` — Session notes, designs, reports, diagrams
- `evidence/` — Screenshots, example logs, demo video

## Roadmap context

This project is part of **Phase B — Industrial Integration** in a structured
roadmap toward industrial embedded systems engineering. Previous phases
(A1–A3) are available in separate repositories.
